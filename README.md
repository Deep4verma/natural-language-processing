# Amazon Sales Data Analysis

## Project Overview

Performed exploratory data analysis on Amazon sales data to uncover customer purchasing patterns, product performance, and business insights. The project focuses on analyzing sales trends, customer behavior, and key factors influencing revenue generation.

## Objective

Analyze Amazon sales data to:

- Identify top-performing products and categories.
- Understand customer purchasing behavior.
- Discover sales trends and patterns.
- Generate actionable business insights through data visualization.

## Dataset

The dataset contains Amazon product and sales-related information.

### Features

- Product Information
- Category Details
- Ratings and Reviews
- Sales Data
- Pricing Information
- Customer Feedback

## Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Data Preprocessing

- Handled missing values.
- Removed duplicate records.
- Cleaned and transformed data.
- Converted data types where required.
- Prepared data for visualization and analysis.

## Exploratory Data Analysis

Performed detailed analysis on:

- Product category distribution
- Customer ratings and reviews
- Sales performance by category
- Price vs Rating relationship
- Best-selling products
- Revenue and demand trends

## Visualizations

Created various visualizations including:

- Bar Charts
- Histograms
- Count Plots
- Correlation Heatmaps
- Distribution Plots
- Category-wise Sales Analysis
